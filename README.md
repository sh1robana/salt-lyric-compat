# FLAC 歌词时间戳兼容模组

## 解决的问题

有些 FLAC 音乐文件已经内嵌了带时间戳的歌词，但 Salt Player 播放时仍把时间戳直接显示为文字，歌词不能随音乐高亮、滚动。

一种原因是小数秒前的分隔符被写成了冒号。例如，这个时间标记表示 **1 分 2.61 秒**：

```text
异常格式：[01:02:61]这是一条示例歌词
标准格式：[01:02.61]这是一条示例歌词
```

本模组在播放器读取歌词时，将这类误写的 `[mm:ss:ff]` / `[mm:ss:fff]` 转为小数点格式，再交给播放器显示。**不会修改音乐文件、标签、封面或音频数据，运行时无需联网。**

### 适用范围

- 处理 **FLAC 内嵌歌词**中符合上述模式的行首时间标记；不能解决所有歌词显示问题，也不处理 MP3。
- 已在 **Salt Player for Windows 1.18.5** 中验证：启用后问题歌曲恢复同步，禁用后重现原问题；正常歌曲及翻译正常显示。
- 其他 Windows 版本、Linux 版尚未验证；当前安装包不适用于安卓版。
- 如果时间标记可能是合理的“时:分:秒”，模组会保守地保留原样。同目录存在同名外置歌词时，也会交回播放器默认处理。

## Windows 下载与安装

### 1. 下载模组安装包

**[点击下载 Windows 安装 ZIP](https://github.com/sh1robana/salt-lyric-compat/releases/download/v0.1.0/plugin-local.salt.lyriccompat-0.1.0.zip)**

文件名为 `plugin-local.salt.lyriccompat-0.1.0.zip`。保存到容易找到的位置，**保留 ZIP 文件，不要解压**。

也可以到 [v0.1.0 发布页](https://github.com/sh1robana/salt-lyric-compat/releases/tag/v0.1.0) 的 **Assets（附件）**中下载这个文件。带 `source` 的文件、`Source code` 和仓库的 `Code → Download ZIP` 都是源码，不是用于导入的模组安装包。

### 2. 在播放器中导入并启用

1. 打开 Windows 版 Salt Player，依次进入 **设置 → 创意工坊 → 模组管理**。
2. 点击页面右上角的 **导入**图标，选择刚刚下载的 `plugin-local.salt.lyriccompat-0.1.0.zip`，然后打开。
3. 在列表中找到 **FLAC Lyric Timestamp Compatibility**，点击这一行右侧的向下箭头，选择 **启用**。如果出现确认框，点击确认；启用后状态应显示 **STARTED**。
4. 先切换到另一首歌，再切回原本无法同步的歌曲，打开歌词页面。修复后的效果是：时间标记不再出现在正文中，当前歌词随音乐高亮和滚动。

如果播放器提示需要重启，按提示重启后再播放。普通用户不用运行本仓库的 `.ps1` 脚本。

### 3. 禁用或遇到问题

在 **模组管理**中点击模组右侧的向下箭头，选择 **禁用**，再重新打开歌曲，即可恢复播放器默认的歌词处理。

如果已经安装了早期本地试包，可以继续使用。需要换成发布包时，先尝试导入；如果提示同 ID 模组已存在，先禁用并删除旧模组，再导入发布包。

导入失败或歌词仍无法同步时，可在 [Issues](https://github.com/sh1robana/salt-lyric-compat/issues) 中提供播放器版本、系统、简短时间标记示例，以及是否使用外置歌词或其他歌词模组。无需上传完整音乐或私人曲库。
