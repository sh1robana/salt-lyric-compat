真实曲库测试读取了 605 首 FLAC，逐一比较规范化结果与官方歌词加载前回调的返回结果。该测试证明回调逻辑，不等同于播放器窗口中的实际滚动显示。

实际安装包测试：使用安装版中的 PF4J 3.14.1 和 API，从最终 ZIP 经插件类加载器加载，验证描述符、启动、发现一个歌词扩展、回调、停止及卸载，全部通过。

播放器界面实测：

- 最终 ZIP 导入成功，启用状态显示 STARTED；重新启动后继续生效。
- 原异常 FLAC 在播放 00:24 和 00:38 时显示不同的当前行，时间标签隐藏，歌词随播放滚动及高亮。
- 正常示例《乙女解剖》保留日文歌词、中文翻译及同步高亮，00:23 与之后的歌词行正常变化。
- 禁用状态显示 DISABLED；重新播放原异常歌曲，00:27 时冒号时间标记直接显示在正文中，重现原问题。

未验证项目：其他播放器版本及其他歌词模组组合。上述播放器界面实测及下节复核均在首次公开发布前完成。

## 发布前复核

2026-10-04 再次使用原安装版 API，重新构建含 sh1robana / Codex 署名、开源链接和 MIT 许可证的安装包：624 项断言及最终包加载测试再次通过。仅发布元数据及说明变动，歌词处理逻辑保持与界面实测版本相同。

安装包只包含本项目的 Java 类、注册信息、许可证及致谢；不包含播放器代码、宿主运行库、DLL 或替换原版播放器的补丁。通过官方 onBeforeLoadLyrics 回调提供转换后的歌词，不修改播放器二进制和音乐文件。

代码复核：运行时使用 Java 标准文件/字符串接口和桌面创意工坊 API，没有 Windows 原生调用、Windows 盘符硬编码或 shell 执行。构建脚本是 Windows PowerShell 脚本，这不代表运行时必须调用 PowerShell。

Linux 桌面播放器的官方发布已经确认，但当前环境无法完成 Linux 实际导入/播放测试，API 和加载器兼容性仍未知。Android 包使用独立分发渠道，官方资料未声明其支持此桌面 PF4J 安装包；本包不列为 Android 可用。平台结论已同步到 README 和发布说明。
